# Decisions Log

## Character Creation

For the MVP, this is limited to Simple Human Commoner. Other races/classes will be added in later. This is done for simplicity. The character starts with 10 HP.

## Tasks

The MVP will rely on an hnour system. Tasks likes “Sprint to next thousand” is honor-only.

## Rerolls

Once a dice is rolled, the result will be locked unless a re-roll is allowed. This is to prevent the user from spamming the dice roll to get a favourable result.

## Task goals

The task goals will have shared colums with a goal JSON column, kind as enum and Zod validation at seed time and read

## Data export

Saved data is shaped for multiple characters and has a version field. This is to allow for backwards compatibility for older versions of the game

## Character Death

When a haracter dies, there will be a full restart from chapter 0. Total XP per player is tracked as the sum across all characters

## Rules help

A `/rules` page in the MVP will give guidance to new players
